起因是一名员工给 Claude 布置了"认真尝试黎曼猜想"的任务。Claude 最初生成了 650 个想法全部失败，在第 651 个想法上协调 60 个子代理运行一天半，执行 2400 条 shell 命令、编写数百个 Python 脚本、对已知 Zeta 零点做了数千次数值检验并让子代理互相审稿；随后下载 54 篇 arXiv 论文核实结果未被他人抢先，并从头独立重证。整个探索消耗 3100 万输出 token。Anthropic 的数学家 Levent Alpöge 与 Ralph Furman 随后接手验证。
